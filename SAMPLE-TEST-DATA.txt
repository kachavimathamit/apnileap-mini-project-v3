PROJECT 1
--------------------------------------------------------------------
Project code (required)........ KLE-CSE-2026-11
Academic year (required)....... 2025-26
Semester (required)............ Semester 6
Project title (required)....... Smart Attendance System Using Facial Recognition
Start date...................... 2026-01-15
Expected completion............. 2026-05-20
First review date............... 2026-02-28

Project title / theme........... Smart Attendance System Using Facial Recognition
Need statement................... Manual roll-call in large lecture halls wastes
                                   5-10 minutes of every class and is easy to
                                   proxy for absent students.
Problem statement................ There is no low-cost, privacy-respecting way
                                   for a single instructor to record attendance
                                   for 120+ students within the first two
                                   minutes of a lecture.
Objective......................... Build a camera-based attendance system that
                                   recognises enrolled students from a single
                                   classroom camera feed and logs attendance to
                                   a database within 2 minutes of class start.
Learning outcomes................ Computer vision pipelines, face embedding
                                   models, database design, edge-case handling
                                   for lighting and occlusion, data privacy.
Foundation courses anchored...... Digital Image Processing; Database Management
                                   Systems; Machine Learning.
Functional blocks................ Camera capture module; face detection and
                                   embedding service; student matching engine;
                                   attendance database; instructor dashboard.
Interfaces........................ USB/IP camera feed; REST API between capture
                                   module and matching engine; web dashboard for
                                   the instructor.
Dependencies...................... Classroom camera hardware; enrolled-student
                                   photo dataset with consent; GPU-enabled lab
                                   machine for model inference.
Expected deliverables............ Working prototype tested in one classroom,
                                   accuracy report, consent and privacy note,
                                   instructor user guide.

Project title / theme........... Campus Lost-and-Found Portal
Need statement.................... Lost items on campus are currently tracked on
                                   a single physical notice board at the security
                                   office, which most students never check.
Problem statement................ There is no searchable, campus-wide record of
                                   lost and found items, so genuine matches are
                                   frequently missed.
Objective......................... Build a web portal where anyone can report a
                                   lost or found item with a photo, and search
                                   existing reports by category, location and
                                   date.
Learning outcomes................ Full-stack web development, image upload and
                                   storage, search/filter UX design, moderation
                                   workflows.
Foundation courses anchored...... Web Technologies; Software Engineering;
                                   Database Management Systems.
Functional blocks................ Report submission form; image storage;
                                   search/filter engine; security-office
                                   moderation queue; notification on match.
Interfaces........................ Public web form; security office admin
                                   panel; email notification service.
Dependencies...................... Object storage for photos; security office
                                   sign-off on the moderation workflow.
Expected deliverables............ Deployed portal, moderation guide for the
                                   security office, demo video.

Academic year (required)....... 2025-26
Semester (required)............ Semester 6
Project title (required)....... Hostel Mess Menu and Feedback Tracker
Start date...................... 2026-01-15
Expected completion............. 2026-05-20
First review date............... 2026-02-20

Project title / theme........... Hostel Mess Menu and Feedback Tracker
Need statement.................... Hostel students have no advance visibility of
                                   the weekly mess menu and no structured way to
                                   give feedback on food quality.
Problem statement................ Menu changes are announced informally and
                                   feedback, when given, is verbal and never
                                   recorded or acted on.
Objective......................... Build a mobile-friendly app that publishes
                                   the weekly menu and collects a daily 1-5
                                   rating with optional comments per meal.
Learning outcomes................ Responsive UI design, REST API design, basic
                                   data analytics for trend reporting, working
                                   with a non-technical stakeholder (mess
                                   committee).
Foundation courses anchored...... Web Technologies; Human-Computer Interaction;
                                   Database Management Systems.
Functional blocks................ Menu publishing module; daily feedback form;
                                   ratings database; weekly trend report for the
                                   mess committee.
Interfaces........................ Mobile web app; mess committee report export
                                   (CSV/PDF).
Dependencies...................... Mess committee agreement to publish the menu
                                   digitally each week.
Expected deliverables............ Deployed app, four weeks of live feedback
                                   data, a trend report template for the mess
                                   committee.
